# Приёмочный чеклист (§16 ТЗ)

- [ ] Публичный Mini App открывается в Telegram: карта, список, фильтры, карточки, избранное
- [ ] Метки обновляются по фильтрам и bbox; на ~10k объектов нет критических зависаний
- [ ] Посуточные объекты показывают календарь; риелтор (бот) и админ управляют занятостью
- [ ] Риелтор создаёт/редактирует/скрывает объект через бот без кабинета Mini App
- [ ] Админ входит в закрытый раздел Mini App: дашборд и очереди
- [ ] Админ добавляет/блокирует риелторов, модерирует объявления, даты, сделки, отзывы
- [ ] Обращение создаётся по клику контакта; тройное подтверждение работает
- [ ] Без трёх подтверждений отзыв не публикуется; один отзыв на сделку
- [ ] Рейтинг только по опубликованным оценкам
- [ ] Статистика с периодом и экспорт CSV/XLSX
- [ ] Несанкционированный доступ к `/api/admin/*` блокируется
- [ ] Бот шлёт уведомления и открывает нужный экран админки по кнопке
- [ ] Есть инструкции админа/риелтора, исходники, доступы, runbook
