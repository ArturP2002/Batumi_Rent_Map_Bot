# Инструкция риелтора

Кабинета в Mini App нет — всё управление через Telegram-бота.

## Доступ

Администратор добавляет ваш Telegram ID. После этого в боте появляются пункты:

- Добавить квартиру
- Мои квартиры
- Календарь
- Обращения
- Подтвердить аренду
- Мой профиль

## Создание объявления

Пошаговая анкета: тип → комнаты → площадь → этаж → цена → район → адрес → точка на карте → удобства → спальные места → описание → превью → модерация.

- До 10 фото (JPEG/PNG/WebP, ≤5 МБ) — через API/последующее редактирование.
- После модерации объект появляется на карте.
- Критические правки (адрес/фото/характеристики) снова уходят на модерацию.

## Актуальность

Раз в ~14 дней бот просит подтвердить актуальность. Без ответа объект будет скрыт.

## Сделки и отзывы

1. Клиент нажимает контакт в карточке → появляется обращение.
2. Вы инициируете «Подтвердить аренду», указываете даты.
3. Клиент и администратор подтверждают.
4. После тройного подтверждения клиент может оставить отзыв (модерируется админом).
