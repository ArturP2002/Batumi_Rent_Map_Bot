# Инструкция администратора

## Вход

1. Откройте бота и нажмите «Открыть админ-панель» (кнопка видна только админам).
2. Либо deep-link Mini App с `startapp=admin`.
3. Сервер проверяет роль на каждом запросе.

## Ежедневные задачи

- **Дашборд** — очереди модерации объявлений, сделок, отзывов.
- **Объявления** — approve / needs_fix / reject / hide / block / archive.
- **Риелторы** — добавить по Telegram ID; блокировка скрывает их объекты.
- **Сделки** — третье подтверждение аренды; при daily проверяется календарь.
- **Отзывы** — publish / reject; рейтинг пересчитывается автоматически.
- **Статистика** — период, конверсии, экспорт CSV/XLSX.
- **Настройки** — периоды актуальности 14/3/4 и справочник районов.

## Важно

- Один Telegram ID может иметь несколько ролей.
- Без подтверждения трёх сторон отзыв не публикуется.
- Экспорт персональных данных только из админ-API и пишется в audit.
